# Vanuza Empreendimentos

Catálogo da loja (moda feminina, masculina e infantil, perfumaria, calçados, bolsas e variedades) com pedido pelo WhatsApp, e a gestão da loja pelo celular.

- **Loja** (`/`): categorias, promoções, busca e filtros, página do produto com fotos, sacola e pedido pelo WhatsApp com a mensagem pronta.
- **Gestão** (`/gestao`): entrada com a digital (ou código no e-mail), cadastro de produto com foto da câmera, promoções em lote, imagem pronta para o status do WhatsApp, categorias e dados da loja.

Next.js 16 + Tailwind 4 + Supabase. Para pôr no ar: [docs/DEPLOY.md](docs/DEPLOY.md).

```bash
npm install
npm run dev   # sem .env.local, mostra produtos de demonstração
```
